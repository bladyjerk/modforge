# Учебный frontend-проект: Студия разработки модификаций для видеоигр (ModForge Studio)

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

**Тема проекта:** Студия разработки модификаций для видеоигр (аналоги — сервисы Nexus Mods, ModDB).  
Сайт студии предоставляет услуги по созданию модификаций для компьютерных игр: от 4K-текстур и новых предметов до скриптовых механик, квестов и оптимизации игрового процесса. Пользователи могут узнать подробнее о студии и её опыте, изучить список поддерживаемых игр, выбрать услугу в каталоге и оформить заявку на разработку мода.

## Структура проекта

- `index.html` — главная страница (промо-баннер с призывом к действию, ключевая статистика студии, популярные услуги с бейджами и быстрый переход к заказу);
- `catalog.html` — каталог услуг с фильтрацией по категориям и карточками с превью;
- `about.html` — страница «О нас» (описание студии, преимущества «Почему выбирают ModForge», поддерживаемые игры и примеры выполненных работ);
- `contacts.html` — контакты студии, интерактивная карта проезда (OpenStreetMap), форма оформления заявки с валидацией и блок FAQ (аккордеон);
- `css/style.css` — стили проекта (БЭМ-архитектура, тёмная геймерская тема, CSS-переменные, Flexbox, CSS Grid, медиазапросы для мобильных устройств);
- `js/main.js` — скрипты интерфейса (модальные окна, валидация полей форм, клиентская фильтрация каталога, плавный скролл кнопкой «Наверх»);
- `images/` — логотип студии (`logo.svg`, также используется как favicon) и локальные изображения карточек;
- `sitemap.xml` — карта сайта;
- `README.md` — документация проекта;
- `.gitignore` — список файлов, исключённых из контроля версий Git.

## Используемые технологии

- HTML5 (семантическая разметка: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<dialog>`, `<details>`, `<summary>`);
- CSS3 (CSS-переменные, методология БЭМ, Flexbox, CSS Grid, Media Queries для адаптивности);
- JavaScript (Vanilla JS, DOM API, валидация форм, управление модальными окнами, обработка скролла);
- Git, GitHub и GitHub Pages.

Сайт состоит из четырёх взаимосвязанных страниц:

## Адаптивность и мобильная вёрстка

Сайт адаптирован для экранов планшетов и смартфонов с помощью медиазапросов (`@media (max-width: 992px)` и `@media (max-width: 768px)`):

- меню шапки и кнопка «Заказать» аккуратно перестраиваются под узкие экраны;
- боковая панель фильтров каталога переходит из вертикального сайдбара в компактную горизонтальную раскладку;
- сетки карточек (`grid`) автоматически уменьшают число колонок до 1–2 в зависимости от ширины вьюпорта;
- блоки контактов и формы заявки выстраиваются в одну удобную вертикальную колонку;
- отступы и размеры шрифтов оптимизированы для сенсорных экранов.

## Архитектура стилей

- **CSS-переменные:** единая палитра тёмной темы (`--color-bg`, `--color-surface`, `--color-primary`, `--color-accent`, `--color-text`), радиусы скругления и размеры контейнеров объявлены в `:root`;
- **Flexbox:** горизонтальное и вертикальное выравнивание элементов шапки, списка меню, хлебных крошек, карточек и колонок подвала;
- **CSS Grid:** раскладка каталога (`catalog-layout`), форма и FAQ контактов (`contacts-layout`), адаптивные сетки карточек (`cards-grid`);
- **БЭМ (Блок-Элемент-Модификатор):** модульное именование классов (`.site-header__nav`, `.card__badge--popular`, `.order-form__input--error`).
